What Exactly Does AgentPost Do?

AgentPost is an autonomous AI email assistant designed to sort inbox messages, summarize customer support threads, and draft replies. Crucially, it demonstrates how to build secure AI agents that safely handle untrusted data and malicious prompt injection attempts.

1

Reads & Classifies

The agent scans incoming emails. Using deterministic regex guardrails, it inspects message bodies to detect Prompt Injection Traps (e.g., hidden commands telling it to leak data or change settings).

2

Blocks Attacks

If a malicious email is flagged as suspect, the agent completely halts execution and refuses to follow instructions hidden inside the text.

3

Human Approval Gate

For normal emails, when the agent drafts a response, it cannot send or save it silently. It triggers a mandatory human check (y/n) before writing to outbox.json.
